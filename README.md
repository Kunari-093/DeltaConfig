# 鼠鼠工具箱 · DeltaConfig

Android root 本机配置工具，读取并认证《三角洲行动》配置，调整画质档位、帧率请求与渲染比例。当前版本 **1.10**，包名 `io.github.deltaconfig`。

[构建安装包](docs/BUILD.md) · [源码](https://github.com/kk041108/DeltaConfig) · [反馈问题](https://github.com/kk041108/DeltaConfig/issues)

觉得工具有用，欢迎在仓库右上角点一颗 **Star**。App 内的项目按钮会打开外部浏览器，Star 由你自行选择。

## 使用前

**本工具需要 root 权限，会修改游戏配置。使用 root 或修改配置可能触发反作弊检测，导致账号受限或封禁。首次使用、写入、还原与恢复默认均有风险告知。**

- Android 8.0（API 26）及以上，设备已 root，安装下表中的目标游戏。
- ARM64 游戏版本。1.7 起按当前库、配置认证和字段结构检测兼容性，取消对单一版本号的硬限制；原验证基线为 **1.201.37117.67 / versionCode 2207**。
- 游戏至少启动一次，生成本机配置后再使用。

1.8 已使用 **1.201.37119.49 / versionCode 2362** 的配套 ARM64 库与配置完成离线验证，修复新版库材料采用 XOR `0x10` 编码时的读取失败。

## 游戏版本选择（1.10）

| 发行版 | Android 包名 | 验证范围 |
| --- | --- | --- |
| 国服 | `com.tencent.tmgp.dfm` | 两版真实库与配置完成离线认证和修改回归 |
| 国际服 · Level Infinite | `com.proxima.dfm` | 官网 ARM64 库结构识别通过；国际服配置与实机待验证 |
| 国际服 · Garena | `com.garena.game.df` | 安装识别、目标隔离和同协议自动检测；尚无国际服配置与运行验证 |

国际服包名依据 [Level Infinite 官方 Google Play 条目](https://play.google.com/store/apps/details?id=com.proxima.dfm) 与 [Garena 官方 Google Play 条目](https://play.google.com/store/apps/details?id=com.garena.game.df)。应用可选择尚未安装的发行版并明确显示状态；安装后读取该包的本机库和配置。国际服沿用已识别协议、路径及字段规则时可自动处理，认证或格式不符时显示具体失败阶段。

切换发行版会清除旧配置快照，各目标使用独立的路径、缓存身份和备份索引。国服旧备份路径保留。备份还原须匹配发行版、设备和游戏安装身份。

已从[官网 Android APK](https://download.dgameglobal.com/DFM/offcial.apk)按范围提取 `1.202.37117.5602 / 2217` 的 ARM64 库，确认 `DeltaForce` 项目名和 XOR `0x5f` 编码，自动定位通过。库对照使用国服配套配置验证共享认证材料；国际服自身的配置认证和运行效果仍待实际文件与设备验证。

## 更新后的兼容性检测

1.7 从当前安装的游戏读取实际版本与库数据，先验证已知位置的认证材料；验证失败时，解析 ARM64 ELF 的可执行区域，依据认证材料函数的指令特征定位新的数据位置。候选须通过 `UserGameplay.ini` 和 `Engine.ini` 的 HMAC 验证，随后检查目标画质字段和渲染配置结构。

自动检测适用于沿用当前认证封装、可识别指令特征与目标字段结构的版本。算法、代码布局或字段结构无法识别时，在对应阶段停止。六档画质、帧率枚举和渲染请求沿用当前配置规则，新枚举需要单独适配。

上次成功识别的数据位置按游戏安装身份缓存；每次使用仍重读认证材料并校验配置。备份记录实际游戏版本与安装身份，读取和提交之间发生游戏升级时停止；跨游戏版本还原也会停止。

1.9 支持同类单字节 XOR 编码变化：从完整 ARM64 装载结构识别代码编码，认证材料在 256 种字节编码中按已知编码优先尝试。每个候选仍须通过配套配置认证。代码扫描、候选数量和认证尝试字节数均有上限，超限时停止处理。

偏移缓存同时记录通过认证的编码数字，下次优先尝试该编码；提示失效时重新探测，每次仍校验 Hash 和 Engine HMAC。缓存不保存密钥或解密后的材料。

## 功能

| 设置 | 可选范围 |
| --- | --- |
| 画质 | 流畅、标准、精致、高清、极致、终极 |
| 帧率请求 | 60、90、120、144、165、185 帧 |
| 渲染比例 | 25%～100%，可校准显示短边 |
| root | 自动检查，以及“授权 root / 重新授权 root”手动检查 |
| 撤销 | 还原最近备份，或清除覆盖项、由游戏重新生成默认设置 |
| 诊断 | 简短错误提示与本机历史日志 |
| 版本检测 | 认证材料定位、双重 HMAC、目标字段结构与安装身份核对 |
| 游戏选择 | 国服、国际服 Level Infinite、国际服 Garena；识别安装状态并记住选择 |

帧率选项写入对应配置请求。实际运行受设备显示模式、性能和游戏规则约束；终极画质的独立资源帧率上限仍由游戏控制。100% 比例使用游戏的 Surface 尺寸夹紧逻辑请求原生目标。

应用只写入 `Engine.ini`、`Game.ini` 的相关字段，`UserGameplay.ini` 作为只读认证上下文。游戏 APK、签名、库和脚本保留原样。

## 操作

1. 按[构建指南](docs/BUILD.md)生成并安装 APK，打开应用并授予 root。
2. 选择目标游戏发行版；自动读取失败时，可点击“授权 root”检查身份，再点“重新读取”。已记住授权时，管理器通常直接放行；拒绝过本应用时，到 root 管理器中允许后重试。
3. 选择画质、帧率和目标渲染比例，点击“确认修改”，核对目标后确认写入。
4. 写入会自动保存原件、校验认证与文件权限。工具不会自动停止游戏；运行中的游戏可能重新保存配置。
5. 撤销修改可选“还原最近备份”。“恢复默认画质设置”清除相关覆盖项，下次启动由游戏按设备重新选择默认值。

手动 root 检查只验证 UID 0，不读写游戏配置。root 授权与文件可见性分别检查；错误码 44 表示文件缺失或访问环境不可见，授权按钮不会修改 root 管理器的策略。

## 本地数据

配置备份位于 `/data/adb/deltaconfig/backups/<Android用户编号>/`，按设备、用户与游戏版本匹配；卸载工具后目录仍保留。历史错误位于本应用私有目录 `error-history.log`，最多约 512 KiB。界面隐藏目标路径，完整本机日志保留定位信息并遮蔽凭据。

本工具不申请网络权限或“所有文件访问权限”。源码与 Star 按钮使用外部浏览器。仓库不包含游戏原件、个人配置、设备日志或签名私钥。

## 构建与测试

在 Windows 上使用 **JDK 17、Android SDK Platform 35、Build Tools 35.0.0**：

```powershell
$env:JAVA_HOME = 'D:\Java\jdk-17'
$env:ANDROID_SDK_ROOT = 'D:\AndroidSdk'
.\build.ps1
python .\tests\run_core_tests.py
```

默认测试使用合成数据。可选真实样本只从明确提供的本地路径读取，不随项目发布。构建会生成开发者自己的签名；自行构建的 APK 与本项目发布版签名不同。
